# Contributing

- Branch names: `type/short-description` (examples: `feature/login-form`, `fix/header-alignment`, `docs/setup-guide`).
- Commit messages: `type: short summary` (examples: `feat: add login form`, `fix: align header`, `docs: add setup guide`).
- Allowed types: `feat`, `fix`, `docs`, `chore`, `refactor`, `test`.
- Use lowercase, kebab-case for branch names, and imperative mood in commit summaries.
- Keep branch names and commit messages short, specific, and descriptive.
- Don't auto-commit AI-generated changes, always manually review
